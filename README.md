# CigPack-A-Defect-Aware-Multi-View-MambaVision-Framework-for-Cigarette-Packaging-Classification-

# Abstract
Defect classification in cigarette packaging is a crucial step in maintaining product quality throughout the manufacturing process. However, these models encounter three main challenges: 1) single-view dependence that overlooks complementary multi-view information; 2) limited cross-view reasoning and adaptive fusion; and 3) inadequate discrimination of hard Damaged–Deformed examples. To address these challenges, this paper proposes a multi-view classification framework built upon a shared MambaVision backbone, augmented with three novel task-specific integration: a Defect-Aware Cross-View Attention (DACVA) module that enables complementary defect evidence to be exchanged across viewpoints, a Quality and Defect-Aware Adaptive Cross-View Feature Fusion (ACVFF) module that learns to emphasize the most diagnostically relevant and dynamically weights each view according to its reliability and defect informativeness, and a Hard Example Contrastive Learning (HECL) enhances feature separation by emphasizing difficult inter-class samples, empirically challenging between Damaged and Deformed decision boundary. The proposed approach is evaluated using the Cigarette Packaging Quality (CPQ-36K) database, which comprises 36,915 images captured from six synchronized viewpoints. Experimental results show that the proposed model achieves a superior classification accuracy of 88.35%, Precision of 90.86%, recall of 88.35%, F1-score of 89.14, significantly outperforms several state-of-the-art models. Moreover, isolated-cam failure analysis indicates only a 2.57% to 3.12% drop in efficiency, indicating that the multi-view representation can withstand the loss of a single camera. These results establish the effectiveness of defect-aware cross-view reasoning and adaptive multi-view representation learning for real-world cigarette packaging quality inspection.
